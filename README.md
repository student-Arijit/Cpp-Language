# C++ DSA & Problem Solving Repository

A well-organized collection of Data Structures & Algorithms problems solved in **C++**, covering everything from basic syntax to advanced competitive programming concepts. This repository serves as a personal learning log and a reference resource for anyone preparing for coding interviews or competitive programming contests.

## 📖 About

This repository contains solutions to problems from various online judges and platforms (LeetCode, Codeforces, GeeksforGeeks, HackerRank, etc.), organized by topic and difficulty. Each solution aims to be clean, well-commented, and optimized, with time and space complexity noted where relevant.

## ▶️ How to Run

Clone the repository:
```bash
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>
```

Compile and run any solution:
```bash
g++ -std=c++17 -O2 -o solution path/to/file.cpp
./solution
```
